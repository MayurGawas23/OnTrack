# 🚀 TrackIt – AI-Powered Habit & Fitness Tracker

TrackIt is a full-stack **AI-powered fitness and habit tracking application** that helps users build discipline, monitor daily activities, and receive personalized fitness insights.

---

## ✨ Features

* 🔐 **Authentication & Onboarding**

  * Secure login/signup with user onboarding
  * Collects goals, body metrics, and lifestyle data

* 🧠 **AI-Powered Recommendations**

  * Generates **personalized workout plans**
  * Suggests **Indian diet plans**
  * Uses intelligent analysis for better guidance

* 📊 **Daily Tracking System**

  * Log food intake, workouts, and activities
  * Track calories, protein, and progress
  * Real-time AI insights and suggestions

* 🎯 **Goals & Habits**

  * Create goals and assign habits
  * Daily, weekly, monthly habit tracking
  * Progress visualization and analytics

* 💬 **AI Chat Interface**

  * Interactive chat for fitness guidance
  * Smart responses based on user data

---

## 🛠️ Tech Stack

**Frontend**

* React (Vite)

**Backend**

* Node.js
* Express.js
* MongoDB (Mongoose)

**AI Integration**

* Google Gemini API

**Deployment**

* Frontend: Vercel

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/your-username/trackit.git
cd trackit
```

---

### 2. Setup Backend

```bash
cd backend
npm install
```

Create `.env` file:

```env
PORT=5000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
GEMINI_API_KEY=your_api_key
```

Run backend:

```bash
npm run dev
```

---

### 3. Setup Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## 🌍 Environment Variables

Make sure to configure:

* `MONGO_URI`
* `JWT_SECRET`
